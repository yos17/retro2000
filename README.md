# Early 2000s Style Landing Page

This project is a nostalgic recreation of a typical personal website from the early 2000s era, featuring:

- No scrolling design (fixed 800x600 resolution)
- Bright, high-contrast colors
- Comic Sans MS font
- "Under Construction" GIF
- Visitor counter
- "Best viewed in Internet Explorer" badges
- Webring links
- Blinking text effects

## Features

- Authentic early 2000s web design aesthetics
- Fixed-size layout with no scrolling
- Animated elements typical of the era
- Navigation menu with fake links
- Sidebar with "About Me" section
- Updates section with dates

## How to Use

Simply open the `index.html` file in a web browser to view the landing page. For the most authentic experience, view it in a window sized to 800x600 pixels.

## Design Choices

This design intentionally incorporates elements that were common in the early days of the web:

- Dark backgrounds with bright text
- Heavy use of primary colors
- Animated GIFs
- Simple table-like layouts
- Decorative borders
- Web badges and counters

## Note

The external images are linked from web archives of GeoCities, a popular free web hosting service from that era. If these images don't load, it means the archive links may have changed or are no longer available.
